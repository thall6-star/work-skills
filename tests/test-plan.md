# Test, pilot and change control

Run the full test set before the pilot and after every change, one change at a time.

| District | What it tests |
|---|---|
| Cedar Plains ISD, TX (fictional; [sample](cedar-plains-isd-sample.md)) | Gold-standard comparison; September fiscal year; three enrollment figures; undated board goals; one attendee with no public background |
| A large district with rich public data | Rich data; approved vs proposed budget; detailed calendar with process clues |
| A small rural district you know | Thin data; optional sections left out |
| A district with a common name | Wrong-district and same-name attendee risk |
| A district with a new superintendent | Strategic Direction In development |

## Discovery Brief checklist

- [ ] "Discovery Prep." alone returns one intake form, once
- [ ] Correct district and file name; chat reply is one or two lines
- [ ] Budget figures are the latest stage and labeled
- [ ] 3 slide bullets that follow the Slide Bullet Rules; page 1 fits one page
- [ ] Bullets match the Bullet Tone Examples in tone and length, and reuse none of their facts or wording
- [ ] Timing Read matches the month rule
- [ ] Every attendee background is about the right person, or says "No public background found"; backgrounds are on page 3, not page 1
- [ ] Source titles and In the News items are clickable links
- [ ] Optional sections with no evidence are left out
- [ ] Call sheet shows the opening and Q1 to Q9 word for word
- [ ] Clues are labeled as clues, never as facts

## Demo Prep checklist

Use 2 to 3 past discovery transcripts with their Discovery Briefs.

- [ ] MEDDPICC table has all 8 rows with status, evidence and next question
- [ ] Information sits under the right component
- [ ] SE Request parts within limits; Timeline uses Q9 or Budget Timing
- [ ] Discovery Answers has one row per Q1 to Q9

## Demo Debrief checklist

Use 2 past demo transcripts.

- [ ] Demo Notes are 3 paragraphs and paste cleanly into Salesforce
- [ ] MEDDPICC Changes use Confirmed, Partial or Gap and say what moved each status
- [ ] Every task has an owner; Playbook Signals has no names

## Pilot

Two reps and one SE for 2 to 3 weeks with no changes. Track SE minutes to prepare for the prep call and which sections reps skip.

## Change control

This repo is the source of truth. Change it first, add a line to [CHANGELOG.md](../CHANGELOG.md) (for example "v3.1, Nov 15: shortened Strategic Direction"), then paste whole blocks into Agent Builder.
